ZALAXYMUSIC PRIVACY POLICY

Version 1.0 — Effective Date: 2026-11-01
Last Updated: 2026-11-01

ZalaxyMusic ("we," "us," "our") respects your privacy. This Privacy Policy explains what data the ZalaxyMusic plugin ("Software") collects, how it is used, and your rights.

1. DATA WE COLLECT

1.1 Local-Only Mode (Default)
When using the Software with local AI inference (ONNX Runtime), NO personal data leaves your computer. All processing occurs locally.

1.2 Cloud AI Features (Opt-In)
When you enable cloud AI features and provide an API key, the following data is transmitted:
- Text prompts you enter (e.g., "bright pluck with short decay")
- Audio snippets you select for analysis (only the selected time range)
- Anonymous usage metrics: feature used, success/failure, latency (no prompt content)

1.3 Update Checks
The Software may periodically check for updates by contacting our server. This transmits:
- Software version
- OS version (Windows 10/11)
- No personally identifiable information

1.4 Crash Reports (Opt-In)
If you enable crash reporting, minimal diagnostic data is sent:
- Crash stack trace
- Software version, OS
- No project files, audio, or prompts

2. HOW WE USE YOUR DATA
- Provide cloud AI features (text-to-patch, audio analysis, assistant)
- Improve Software stability (crash reports)
- Notify you of updates
- We do NOT sell your data. We do NOT use your prompts/audio to train models.

3. DATA SHARING
3.1 Third-Party AI Providers
When using cloud features, your prompts/audio are sent to the AI provider you choose (Together AI, OpenRouter, Groq, etc.). Their privacy policies apply.

3.2 Our Proxy Server
If you use our proxy (recommended), we log only: timestamp, feature used, success/failure, latency. Prompt/audio content is NOT logged.

3.3 Legal Requirements
We may disclose data if required by law, court order, or to protect our rights.

4. DATA RETENTION
- Proxy logs: 30 days (aggregated metrics retained longer)
- Crash reports: 90 days
- No long-term storage of prompts or audio

5. YOUR RIGHTS
- Disable cloud features anytime (Settings → Local Only)
- Request data deletion: email legal@zalaxymusic.com
- Opt out of update checks/crash reporting in Settings
- GDPR/CCPA: You have access, rectification, erasure, portability rights

6. SECURITY
- All network communication uses TLS 1.2+
- API keys stored encrypted in your OS keychain (Windows Credential Manager)
- No authentication system — no passwords to breach

7. CHILDREN'S PRIVACY (COPPA)
The Software is not directed at children under 13. We do not knowingly collect data from children. If you are a parent/guardian and believe we have collected data from a child, contact us.

8. INTERNATIONAL TRANSFERS
Cloud AI providers may process data in the U.S. or other countries. By using cloud features, you consent to this transfer.

9. CHANGES TO THIS POLICY
We will notify you of material changes via the plugin update mechanism or website. Continued use constitutes acceptance.

10. CONTACT
Questions: legal@zalaxymusic.com
DMCA Agent: dmca@zalaxymusic.com

This policy applies worldwide. For EU/UK users: Legal basis = legitimate interest (updates, crash reports) and consent (cloud AI).
